# 🐾 Paws & Preferences: Find Your Favourite Kitty

**Paws & Preferences** is a mobile-friendly single-page web application that helps users discover their favourite types of cats through an interactive, swipe-based experience inspired by popular dating apps.

Users can swipe **right to like** or **left to dislike** a series of cat images sourced from the **Cataas (Cat as a Service) API**. Once all cats have been viewed, the app displays a summary of the cats the user liked along with the total number of favourites selected.

The application focuses on smooth touch interactions, intuitive UI/UX design, and a pleasant mobile viewing experience. Design decisions, animations, and implementation details were kept flexible to encourage creativity and experimentation.

## ✨ Key Features
- Swipe-based **like/dislike** interaction for cat images  
- Summary view showing **liked cats and total likes**  
- Images dynamically fetched from the **Cataas API**  
- **Responsive, mobile-first UI** optimized for touch gestures  
- Single-page application with smooth transitions
